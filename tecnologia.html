Alcance

Multiplataforma por design

Em vez de um aplicativo separado para cada sistema, o Convive é uma aplicação web responsiva: um único código-fonte que se adapta ao tamanho de tela, ao tipo de entrada (toque, mouse ou teclado) e à capacidade do dispositivo, sem exigir instalação ou loja de aplicativos.

Celular

Layout de coluna única, botões grandes o bastante para toque.

Tablet e notebook

Aproveitamento do espaço extra, navegação completa por teclado.

Computador

Interface em tela cheia, ideal para uso prolongado em sala de aula.

Por dentro do código

Como fizemos isso?

Nenhum recurso de acessibilidade deste site é uma imagem ou uma promessa — é uma cadeia curta e concreta de HTML, CSS e JavaScript. Este é o caminho exato que uma preferência percorre, do clique até ficar salva.

1

HTML semântico

Cada botão de ajuste é um <button> real, com data-toggle, data-motor ou data-font identificando o que ele controla — não uma <div> clicável.

2

JavaScript identifica a ação

Um clique dispara um event listener que lê o atributo do botão (ex: data-toggle="high-contrast").

3

Uma classe é aplicada

O JavaScript adiciona essa classe no elemento raiz da página: <html class="high-contrast">.

4

CSS reage à classe

Regras que já existem no CSS mudam cor, espaçamento ou tamanho assim que essa classe aparece no HTML.

5

A preferência é salva

O JavaScript grava a escolha no localStorage do navegador — não em um servidor. Ao reabrir o site, o mesmo script lê essa memória e reaplica a classe antes da página terminar de carregar.

Esse mesmo padrão — atributo no HTML → classe via JavaScript → regra no CSS → gravação no localStorage — se repete para todos os controles do painel de acessibilidade, incluindo os perfis prontos, que só aplicam vários desses passos de uma vez.

Honestidade técnica

Como testamos

Alguns itens abaixo a gente já verificou com as próprias mãos, no código. Outros ainda não — e preferimos dizer isso claramente a fingir que está tudo validado.

Já verificamos
  • Navegação completa usando apenas o teclado (Tab, Shift+Tab, Enter, Esc)
  • Indicador de foco visível em todos os elementos interativos
  • Contraste de cores nos temas padrão e de alto contraste
  • As 7 paletas de daltonismo, com uma ferramenta de simulação
  • Comportamento com "reduzir movimento" ativado
  • Redimensionamento de tela (celular, tablet, notebook, desktop)
  • Zoom do navegador até 200%
Ainda não testamos
  • Uso real por pessoas com deficiência visual, motora ou cognitiva
  • Teste formal com leitores de tela dedicados (NVDA, JAWS, VoiceOver)
  • Avaliação por um especialista externo em acessibilidade
  • Testes automatizados de acessibilidade (ex: axe, Lighthouse)

Não afirmamos que o Convive foi validado por pessoas com deficiência, porque isso não aconteceu nesta fase do projeto. O que existe hoje é um conjunto de recursos funcionais, verificados por nós mesmos durante o desenvolvimento — o próximo passo real seria testar com usuários de verdade.
